API Key
📋 不知道怎么获取 API Key？点这里看详细步骤 ›
1
注册智谱账号（免费）
打开 open.bigmodel.cn，用手机号注册登录。新用户送免费额度，日常使用基本够用。
2
进入 API Keys 管理页
登录后，点击右上角头像 →「API Keys」，或直接访问：
open.bigmodel.cn/usercenter/proj-mgmt/apikeys
3
创建 API Key
点击「添加 API Key」，随便起个名字（如"穿搭App"），创建后会生成一串以 sk- 开头的密钥。
4
复制粘贴到上方输入框
点「复制」把 Key 复制下来，粘贴到上方的「API Key」输入框，然后点「保存配置」即可。
💡 费用说明：智谱新用户有免费额度。日常打标签+搭配+海报，每月大概几毛到几块钱。可在智谱后台「财务中心」设置消费上限，避免超额。
🔒 Key 仅保存在你本机浏览器（localStorage），不会上传服务器，不进入代码。
建议在智谱后台设置消费上限。
