📝 配置步骤（共4步）

1
注册智谱开放平台账号（免费）
用手机号注册并登录智谱开放平台。新用户注册即送免费额度，日常穿搭使用基本够用。 前往注册 →
2
进入「API Keys」管理页
登录后，点击右上角头像 →「API Keys」，或直接访问下方链接： 打开 API Keys 页面 →
3
创建一个新的 API Key
点击「添加 API Key」按钮，起个名字（比如"穿搭App"），创建后会生成一串以 sk- 开头的密钥字符串。
🔐 创建后这里会显示你的密钥，形如：
sk-xxxxxxxxxxxxxxxxxxxx
⚠️ 重要：密钥只在创建时完整显示一次，请立即复制保存。如果忘了复制，删掉重建一个即可。
4
回到智能穿搭 App，粘贴并保存
打开智能穿搭 App →「我的」→「AI 配置」→ 把刚才复制的密钥粘贴到「API Key」输入框 → 点「保存配置」。
📱 路径：我的 → 🤖 AI 配置 → 粘贴 Key → 保存
看到「✓ AI 配置已保存」的提示就完成了，可以开始添加衣物和使用 AI 功能啦！

❓ 常见问题

为什么要我自己配置 API Key？
这样 AI 的费用由你直接付给智谱（官方价格，无加价），你的数据也只在你手机里处理，更隐私更安全。App 本身完全免费。
我的 Key 会被别人看到吗？
不会。Key 只保存在你手机浏览器的本地存储（localStorage）里，不会上传到任何服务器，也不会进入代码。换手机需要重新配置。
配置后提示"请求失败(401)"？
说明 Key 不正确或已失效。请回到智谱 API Keys 页面，重新复制完整的 Key（以 sk- 开头），注意前后不要有空格。
提示"请求失败(403)"或"余额不足"？
免费额度用完了。登录智谱后台「财务中心」充值即可，10 元够用很久。
能不能不用智谱，用别的 AI？
在「AI 配置」里选「自定义（OpenAI 兼容接口）」，填入其他厂商的接口地址和模型名即可（需支持视觉和生图能力）。
换手机了，Key 还在吗？
不在。Key 绑定在当前手机的浏览器里，换手机需要重新配置（Key 不变，只是重新粘贴一次）。
